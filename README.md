## 1. Objective

To implement Logistic Regression for binary classification and evaluate its performance using different classification metrics.

## 2. Dataset Information

- **Dataset:** Breast Cancer Wisconsin Dataset
- **Source:** Scikit-learn
- **Total Records:** 569
- **Input Features:** 30 numerical features
- **Target Variable:** Diagnosis
- **Class 0:** Malignant
- **Class 1:** Benign

Dataset source: https://scikit-learn.org/stable/datasets/toy_dataset.html#breast-cancer-dataset

## 3. Technologies Used

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 4. Activities Performed

1. Loaded and inspected the dataset.
2. Checked missing values, duplicates and class distribution.
3. Separated input features and target variable.
4. Applied stratified 80:20 train-test splitting.
5. Performed feature scaling using StandardScaler.
6. Explained the sigmoid function and Logistic Regression.
7. Trained the Logistic Regression model.
8. Generated class predictions and probabilities.
9. Evaluated performance using accuracy, precision, recall, specificity and F1-score.
10. Created a confusion matrix and classification report.
11. Plotted the ROC curve and calculated AUC.
12. Compared the model with a majority-class baseline.
13. Compared classification thresholds of 0.3, 0.5 and 0.7.
14. Compared training and testing accuracy.
15. Visualized the decision boundary using two features.
16. Tested prediction on a new record.

## 5. Evaluation Metrics

- Accuracy
- Precision
- Recall (Sensitivity)
- Specificity
- F1-score
- Confusion Matrix
- ROC Curve
- AUC Score

## 6. Conclusion

Logistic Regression was implemented successfully using the Breast Cancer Wisconsin dataset. The model was trained using scaled numerical features and evaluated using multiple classification metrics.

The project also included baseline comparison, threshold analysis, ROC-AUC evaluation, training and testing performance comparison, and decision boundary visualization.

This project demonstrates the application of Logistic Regression for binary classification. It is intended for academic purposes and not for medical diagnosis.
